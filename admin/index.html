Dickson Antiquities — Content Admin

Edit the parts of the site that change often. The repository is the source of truth; these tools are a window onto it.

Featured Finds Manager

The nine featured item tiles on the homepage — title, price, eBay link, and image (local upload or remote URL) for each slot.

Writes featured.json + images/featured/

Showcase Manager

The list of eBay item IDs the “From Our Collection” section pulls from. Add, remove, and reorder IDs.

Writes showcase.json (consumed by the Cloudflare Worker)
Workflow: open a manager → current content loads automatically → edit → Save to Repository → review the change with git status / git diff → git commit → git push. Pushing is still what deploys the site (and refreshes the Worker’s source). The Instagram section is Worker-driven and has no manager.
